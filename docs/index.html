Get Started

Install DiskTile on your Mac in seconds

Choose between Homebrew, the standalone .app bundle, or building directly from source via Swift Package Manager.

Terminal — zsh
# Option 1: Clone from GitHub and compile native DiskTile.app with Swift Package Manager
git clone https://github.com/risov/disktile.git && cd disktile && ./scripts/package_macos_app.sh
# Option 2: Run directly from Terminal in release mode without installation
cd disktile/DiskTile && swift run -c release
# Option 3: Run standalone POSIX CLI scanner without GUI (outputs JSON metrics)
./scripts/storage_scanner.sh ~ 2 true

FAQ

Frequently asked questions

Everything you need to know about permissions, safety, and compatibility.

Does DiskTile require Full Disk Access on macOS? +
Scanning your normal user Home folder (~/) and Downloads works immediately. However, if you want to scan protected system directories such as ~/Library/Application Support, ~/Library/Caches, or the entire root drive (/), macOS requires Full Disk Access. You can enable it in System Settings → Privacy & Security → Full Disk Access.
Is moving items to Trash safe? Can I recover deleted files? +
Yes, 100%! DiskTile uses Apple's official FileManager.default.trashItem(at:resultingItemURL:) API. When you drag a tile to the Trash or click "Move to Trash", the file is safely moved into the macOS Trash bin. You can easily open Trash in Finder and click "Put Back" at any time.
Which macOS versions and Macs are supported? +
DiskTile is compatible with macOS 13 (Ventura), macOS 14 (Sonoma), and macOS 15 (Sequoia). It is compiled as a Universal 2 binary, providing native blazing-fast performance on both Apple Silicon (M1, M2, M3, M4) and Intel Macs.
Does DiskTile send any data over the network? +
No. DiskTile is strictly 100% offline and privacy-first. There are zero analytics, no telemetry, no tracking scripts, and no internet network permissions required.
